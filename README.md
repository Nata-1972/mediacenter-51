# Медиацентр 51

Адаптивный веб-прототип цифрового штаба медиацентра ГБОУ ЛНР «ЛУВК № 51 имени 10-летия Республики».

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Результат сборки создаётся в каталоге `dist`.

## Публикация на Render через Blueprint

1. Создайте отдельный GitHub-репозиторий для содержимого этой папки.
2. Отправьте проект в ветку `main`.
3. В Render выберите **New → Blueprint**.
4. Подключите созданный GitHub-репозиторий.
5. Render автоматически прочитает `render.yaml` и создаст Static Site.
6. После завершения сборки откройте выданный адрес `onrender.com`.

Blueprint использует следующие параметры:

- среда: `Static Site`;
- команда сборки: `npm ci && npm run build`;
- публикуемый каталог: `dist`;
- Node.js: версия 22 из `.node-version`;
- автоматические preview-развёртывания для pull request;
- SPA-rewrite на `index.html`;
- базовые защитные HTTP-заголовки.

## Публикация через Render Dashboard

Если Blueprint не используется, создайте **Static Site** вручную со следующими настройками:

| Параметр | Значение |
| --- | --- |
| Build Command | `npm ci && npm run build` |
| Publish Directory | `dist` |
| Node Version | `22` |
| Auto-Deploy | `Yes` |

Добавьте Rewrite Rule:

| Source | Destination | Action |
| --- | --- | --- |
| `/*` | `/index.html` | Rewrite |

## Репозиторий

Проект расположен в корне отдельного Git-репозитория. При подключении к Render дополнительный **Root Directory** не требуется.

## Ограничения демонстрационного режима

- Данные новых материалов и изменения Kanban хранятся в `localStorage` браузера.
- Данные не синхронизируются между устройствами и пользователями.
- Авторизация, серверная модерация и защищённое файловое хранилище пока представлены только интерфейсом.
- Для реальной работы с персональными данными несовершеннолетних потребуется отдельный backend, база данных и серверное разграничение прав.
